# Keasy KI in Azure einrichten – umgezogen

> **Dieses Repository ist archiviert und wird nicht mehr gepflegt.**

Die Anleitung zur Einrichtung der Keasy-KI in Microsoft Azure steht jetzt in der Keasy-Dokumentation im Supportportal:

**➡️ [KI-Zugang einrichten](https://support.keasy.de/hilfe/ki/einrichtung/ki-zugang)**

Dort finden Sie alle drei Wege:

- **Anwender im vfm-Verbund:** Keasy ruft das KI-Modell automatisch ab – nichts zu tun.
- **Einrichtungsassistent:** [keasyki-onboarding.azurewebsites.net](https://keasyki-onboarding.azurewebsites.net) legt Ressource und Modelle in Ihrem eigenen Tenant an.
- **Manuelle Einrichtung für Administratoren und IT-Dienstleister:** [KI-Zugang manuell in Azure einrichten](https://support.keasy.de/hilfe/ki/einrichtung/ki-zugang-manuell) – inklusive REST-Aufrufen, Verbindungstest und häufigen Fehlern.

Die früheren Inhalte (`README.md`, `DEPLOYMENT_GUIDE.md`, ARM-Vorlage `azuredeployopenai.json`) sind veraltet und bleiben nur in der Git-Historie erhalten.
